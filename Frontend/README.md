📌 Project Name: Code Audit Review
AI-powered  Code Review using Google Gemini

🚀 Features
✅ AI-based code review using Google Gemini
✅ Identifies best practices & potential bugs
✅ Suggests performance improvements
✅ Supports MERN stack (MongoDB not included)
✅ User-friendly interface for developers

🛠 Tech Stack
Frontend: React,  CSS
Backend: Node.js, Express
AI Model: Google Gemini API
Version Control: Git & GitHub

⚙️ Installation & Setup
1️⃣ Clone the Repository

git clone https://github.com/your-username/code-audit-review.git
cd code-audit-review

2️⃣ Install Dependencies
npm install

3️⃣ Add Environment Variables
Create a .env file and add your API key:
GOOGLE_GEMINI_API_KEY=your_api_key_here

4️⃣ Start the Development Server
npm run dev  # For frontend
npm run start  # For backend


📝 Usage
Upload or paste your  code.
Google Gemini will analyze the code and provide a review.
View AI-generated suggestions, best practices, and improvements.
